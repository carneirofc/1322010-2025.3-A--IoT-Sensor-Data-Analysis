# UFJF technical report template

Kickstart template for **technical reports at UFJF** (Universidade Federal de Juiz de Fora) in the
**ABNT** format (NBR 14724 / NBR 10719). Write Markdown, get a **PDF** (LuaLaTeX) and an editable
**DOCX** from the same sources.

Extracted and generalised from the report build in
[`1322009-2025.3-A--Sensor-Data-Processing-Smart-Greenhouse`](https://github.com/carneirofc/1322009-2025.3-A--Sensor-Data-Processing-Smart-Greenhouse/tree/main/docs/relatorio).

## Start a new report

```bash
gh repo create my-report --private --template carneirofc/ufjf-technical-report-template --clone
cd my-report
$EDITOR report.yaml        # cover, title page, abstracts
$EDITOR content/*.md       # chapters
make                       # -> build/relatorio.pdf + build/relatorio.docx
```

## What you edit

| Path | Purpose |
|---|---|
| `report.yaml` | Everything pretextual: institution, department, course, authors, title, *natureza*, advisor, city/year, resumo + palavras-chave, abstract + keywords, fonts, lists of figures/tables. |
| `content/NN-*.md` | Chapters, concatenated in filename order. `# Heading` = section. Keep `99-referencias.md` last among the chapters; appendices go after it as `content/apendice-*.md` (letters sort after digits). |
| `bib/references.bib` | BibTeX entries. Cite with `[@key]`, `[@key, p. 10]` or `@key`. |
| `figures/` | Images (`![Caption.](file.png){width=60%}`), optionally followed by a `Fonte: ...` line. |
| Code from a file | ```` ```{.python include="../analise/script.py"} ```` (empty block) is filled with that file's text by the filter; the path is relative to the report folder. The container mounts the report's parent folder, so `../` paths work in both build modes. |
| `diagramas/` | Diagrams as Graphviz `.dot` text files. The build renders `diagramas/NAME.dot` to `figures/NAME.png` (DOCX) and `figures/NAME.pdf` (vector, used by the PDF); reference them as `NAME.png`. |

## What's generated for you

- **Capa** and **folha de rosto** (logo, institution, course, authors, title, *natureza do trabalho*, optional advisor, city/year)
- **Resumo** / **Abstract** pages with keywords (drop either by leaving it empty)
- **SUMÁRIO** (+ optional *lista de figuras/tabelas*), numbered sections, primary titles in bold caps
- A4, margins 3/2/3/2 cm, 12 pt, 1.5 spacing, page number top-right from the first textual page
  (pretextual pages counted, not printed)
- Figure and table captions above (`Figura 1 – ...`, `Tabela 1 – ...`), `Fonte:` line below; caption,
  body and `Fonte:` kept together in one float (never split across pages). The DOCX gets the same
  order and numbering from the filter.
- ABNT references via `template/csl/abnt.csl`
- DOCX with the same structure; TOC moved after the abstracts, fields refreshed when opened in Word

## Make targets

| Target | Does |
|---|---|
| `make` / `make all` | PDF + DOCX into `build/` |
| `make pdf`, `make docx` | One format |
| `make watch` | Rebuild the PDF on save (needs `entr`) |
| `make reference-docx` | Regenerate `template/docx/reference.docx` (DOCX styles) |
| `make image` | Rebuild the container image |
| `make clean` | Remove `build/` |

`OUT_NAME=foo make` changes the output file name.

## Toolchain

`scripts/build.sh` uses a local `pandoc` (≥ 3.8) + `lualatex` + `python3` if they exist; otherwise it
builds `Containerfile` (pandoc/extra + TeX Gyre fonts + Portuguese babel) once and runs inside it
with podman or docker. Force either with `BUILD_MODE=native|container`.

Native on Arch/CachyOS (roughly): `pandoc-cli texlive-luatex texlive-latexextra texlive-fontsrecommended texlive-langportuguese graphviz ttf-liberation`.

CI (`.github/workflows/build.yml`) builds both formats on every push and uploads them as the
`relatorio` artifact.

## Layout

```
report.yaml                  metadata (the only file needed for cover/abstract)
content/                     chapters (Markdown)
bib/references.bib           bibliography
figures/  assets/            images; assets/ufjf-logo.jpg is the cover logo
diagramas/                   Graphviz sources for diagrams (rendered into figures/ by the build)
template/
  filters/ufjf-front.lua     builds capa/folha de rosto/resumo/abstract; figure/table floats with Fonte
  latex/header.tex           LaTeX preamble (ABNT headings, page numbers, captions, code wrapping)
  pandoc/{common,pdf,docx}.yaml  pandoc defaults files
  docx/reference.docx        DOCX styles (generated by scripts/make_reference_docx.py)
  csl/abnt.csl               ABNT citation style (CSL, CC BY-SA 3.0)
scripts/
  build.sh                   build entry point (native or container)
  fix_docx.py                DOCX post-processing (TOC position, properties)
  make_reference_docx.py     generates reference.docx from pandoc's default
```

## Notes

- The DOCX table of contents is a Word field: it fills in when the document is opened in Word
  (it asks to update fields). LibreOffice: *Tools → Update → Update All*.
- Fonts: default is TeX Gyre Termes (free Times clone). Set `mainfont: Times New Roman` in
  `report.yaml` if it's installed locally; the container doesn't ship Microsoft fonts.
- Cross-references (`Figura 1`, `Tabela 2`) aren't automatic; add
  [pandoc-crossref](https://github.com/lierdakil/pandoc-crossref) to `template/pandoc/common.yaml` if needed.
- The UFJF logo belongs to UFJF; it's here for institutional documents.
